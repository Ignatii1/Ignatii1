# inbox/

Zero-friction capture. Paste anything here in any shape — a ticket body, a chat log, a
half-finished thought, a stack trace, a screenshot. No frontmatter, no filename convention,
no thinking required.

Friction at capture time is what kills knowledge systems. Optimise for "dump it in 3 seconds";
structure is applied later, in batch, by the `capture` skill.

Run `capture` when this folder gets noisy (or weekly, via `review`). Files are deleted once
filed — if it is still here, it is not yet knowledge.
